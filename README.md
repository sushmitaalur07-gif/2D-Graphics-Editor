# 2D Graphics Editor

A simple 2D Graphics Editor developed in C that allows users to create and display basic geometric shapes using ASCII characters (`*` and `_`).

## Features

- Draw Rectangle
- Draw Circle
- Draw Line
- Draw Triangle
- Add multiple objects to a picture
- Display the complete picture on the console

## Technologies Used

- C Programming Language
- Standard C Libraries
- Console-based Interface
